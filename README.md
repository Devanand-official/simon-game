# 🧠 Simon-Game

A classic memory-based game where players must repeat an ever-growing sequence of colors and sounds.
This project is perfect for showcasing JavaScript logic, sequencing, event handling, and DOM animations.

### 🚀 Live Demo
🌐 https://devanand.is-a.dev/simon-game/

### 🔧 Features:
- Interactive design with visual and sound cues
- Smooth gameplay experience
- Event-based user input system
- Fully beginner friendly
  
### 🛠️ Technologies Used:
- HTML
- CSS
- JavaScript
